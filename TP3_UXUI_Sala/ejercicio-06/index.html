Demostración de selectores de Clase, de ID y Descendientes.

Módulo Destacado

Este párrafo está estilizado mediante un selector descendente: .card p. La tarjeta posee además un ID para resaltar con mayor especificidad.

Nivel Avanzado

Fundamentos de CSS

Los selectores descendientes permiten aplicar estilos a elementos anidados dentro de una clase contenedora sin afectar a otros párrafos del documento.

Nivel Básico

Aviso general: Los selectores de ID tienen mayor especificidad que los selectores de clase y de tipo.
