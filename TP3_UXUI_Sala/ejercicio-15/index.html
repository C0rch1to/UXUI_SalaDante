Diseño Responsivo: Enfoque Mobile-First

Justificación del enfoque Mobile-First: Se diseña primero la experiencia base para pantallas móviles (1 columna fluida, sin sidebar para priorizar el contenido esencial y evitar scroll horizontal innecesario). Mediante dos breakpoints progresivos (@media (min-width: 768px) y @media (min-width: 1024px)), se incorporan gradualmente el sidebar y la distribución multi-columna de widgets aprovechando pantallas de mayor tamaño.

Comportamiento según el ancho de pantalla

  • < 768px (Móvil): El sidebar se oculta con display: none, el grid pasa a una sola columna (1fr), y los elementos se apilan naturalmente sin desbordamiento horizontal.
  • ≥ 768px (Tablet): El sidebar se hace visible (display: block) con ancho de 200px, y el grid adopta áreas estructuradas.
  • ≥ 1024px (Desktop): El sidebar se expande a 250px con tipografía optimizada y los widgets se distribuyen en 3 columnas independientes.
