Sistema de Tokens CSS

Demostración de Custom Properties (Variables CSS)

Las variables CSS definidas en :root se aplican de manera dinámica en múltiples propiedades: colores de fondo, colores de texto, tamaños de espaciado, radio de bordes y sombras.

Reutilización Consistencia Mantenibilidad

Token: Color Primario

Se aplica a titulares, bordes de acento y botones con var(--color-primario).

Ver especificación →

Token: Superficie y Fondo

Al activar el switch superior, --color-fondo y --color-superficie se reasignan instantáneamente.

Ver especificación →

Token: Espaciados

Márgenes y paddings calibrados con variables homogéneas --espaciado-sm, --espaciado-md y --espaciado-lg.
