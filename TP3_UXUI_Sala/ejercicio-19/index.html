Registro de Usuario en 2 Pasos

Formulario multi-etapa 100% HTML/CSS con radio buttons y validación visual nativa (:valid, :invalid, :required).

Paso 1: Información de Acceso

Debe tener al menos 4 caracteres. ✓ Usuario válido
Ingresa un correo electrónico con formato válido. ✓ Correo válido
La contraseña debe tener mínimo 8 caracteres. ✓ Contraseña con longitud válida

Paso 2: Información Personal

Este campo es obligatorio. ✓ Nombre completo ingresado
Ingresa entre 8 y 15 dígitos numéricos. ✓ Teléfono válido
Selecciona una opción de la lista. ✓ Opción seleccionada
